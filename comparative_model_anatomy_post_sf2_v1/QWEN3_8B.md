## 2. Training-recipe research

- Pretraining ~36T tokens over 119 languages. **[DOC]**
- Three pretraining stages: S1 >30T tokens at 4K context; S2 +~5T tokens with a raised proportion of
  knowledge-intensive data (STEM/coding/reasoning); S3 long-context extension with high-quality long data to
  32K. **[DOC]** => staged pretraining with explicit per-stage data-mixture changes and a dedicated
  context-extension stage.
- Post-training in four stages: (1) long-CoT cold-start SFT; (2) reasoning RL; (3) "thinking-mode fusion" SFT
  that mixes long-CoT data with ordinary instruction data (generated by the stage-2 model) to fuse thinking and
  non-thinking behavior in one model; (4) general RL across >20 domains. **[DOC]**
- Smaller-scale models "leveraging the knowledge from the flagship models ... reduce the computational resources
  required to build smaller-scale models." **[DOC]** (mechanism — e.g., logit KD vs teacher-generated data — not
  specified in the sources read; UNKNOWN).
- Exact optimizer / peak LR / warmup / decay schedule for Qwen3-8B: UNKNOWN from the sources read (not in the
  blog; full technical report was not exhaustively mined here).
- Explicit retention mechanism for old capabilities while learning new: the "fusion" SFT stage re-trains the
  model on BOTH the new capability data and the prior instruction data in a single mixture — i.e., capability
  retention by data re-mixing rather than by a distributional regularizer. **[DOC][INF]**

## 3. Baby-relevance

- Thinking/non-thinking fusion stage = direct, documented precedent for **retaining an old objective while adding
  a new one by mixing both datasets in a dedicated SFT stage** (rather than only adding a regularizer). This is
  the closest large-model analog to Baby's "add factual skill without destroying ordinary language": Qwen3 did
  not freeze old blocks or use a KL; it re-exposed the model to both data classes in one stage. DIRECTLY RELEVANT
  to the replay/rehearsal family (candidate 5) and to staged training (candidate H). Important difference: it is
  an SFT post-training stage at ~1e13-token scale with a large model, not a 200-update fine-tune on 16 records.
- QK-norm: an explicit stabilizer of attention logits per head. Baby's demonstrated problem is an output-layer
  boundary offset, not attention logit spikes; QK-norm is PLAUSIBLY RELEVANT only to the separate
  attention/localizer machinery and is not implicated by SF2 evidence. INTERESTING BUT CURRENTLY IRRELEVANT for
  the residual AO item.
- Small-models-from-flagship (distillation) statement: supports the general family of "small model learns from a
  teacher distribution", but the source does not specify logit KD; and Baby's SF2 KL is self-distillation from
  an earlier snapshot (same model), which is structurally different from cross-model distillation. PLAUSIBLY
  RELEVANT (family-level), INSUFFICIENT EVIDENCE for a specific KL design.
- Untied embeddings at 8B while ≤4B variants tie: within one family the tie decision flips with scale; this is
  strong evidence that "tied vs untied" is a scale/engineering trade-off, NOT a principle that predicts the
  output-head behavior Baby observed. NOT APPLICABLE as a directional signal.

## Scorecard

MODEL: Alibaba Qwen3 8B
MOST RELEVANT LESSON: staged pretraining with per-stage data-mixture changes, and a **fusion SFT stage that mixes
new-capability data with old-capability data** to add a behavior without losing the prior one; QK-norm used as an
explicit attention stabilizer.
WHY IT MAY MATTER TO BABY: gives an independent, documented precedent for "retain old by re-mixing old data with
new in a dedicated stage" (relevant to Baby's language-vs-factual retention) and shows careful scale handling of
heads/embeddings (tie only at small sizes) rather than any universal rule.
EVIDENCE QUALITY: architecture [LOCAL] high + [DOC] high; training stages [DOC] high (blog/report); exact
optimizer/LR values UNKNOWN in sources read.
BIGGEST ANALOGY LIMITATION: fusion-stage SFT is a data-mixing choice at post-training scale, not a distributional
retention term and not evidence about 200-update micro-fine-tunes; QK-norm addresses attention stability, which
Baby's SF2 residual did not implicate.
ONE IDEA WORTH CARRYING FORWARD: if Baby ever re-runs with language rehearsal, model it on a *dedicated mixing
stage* (fixed language fraction, fixed budget) rather than ad hoc interleaving — the "fusion stage" framing.
ONE IDEA NOT WORTH COPYING: switching Baby to QK-norm or untied/tied changes as a response to the SF2 boundary
offset (no evidence it bears on the residual).
