# DaveLM experiments and the Mangaris family tree

**DaveLM** is the project; **Mangaris** is the model family; **RNC (Racina
Neural Core)** is the active architecture lineage; **Baby** is the development
codename. The current research model is **RNC-1, 91,246,848 parameters**.

```text
DaveLM / Mangaris
  Historical research
    Earlier 61M museum graduate        C:\DaveLM-v1.0\
    MRCN-Alpha and certified S1/S2      C:\DaveLM_ARCHIVE\MRCN-Alpha_LAB_20261016\
  Active RNC lineage                   C:\DaveLM-Training\rnc\
    Baby / RNC-1 (91.25M)              first 3,000-step TinyStories run completed
    Future Adam & Eve foundation       NOT CREATED / NOT GRADUATED
      Future descendants               C:\DaveLM-Experiments\RNC\
        Instruct / Reasoning / Coder / Writer / Personal / Other
```

This is a conceptual research tree. RNC starts from random initialization and
its own tokenizer; there is no weight-inheritance edge from the historical
models. The first 3,000-step TinyStories run demonstrates language-model
learning, not general conversational competence. S1/S2 certifications remain
accomplishments of the preserved historical MRCN-Alpha models.

The future Adam & Eve checkpoint has not been created or graduated. The six
specialist directories are documentation placeholders. Instruct, Reasoning,
Coder, Writer and Personal should eventually originate from a verified common
foundation; Other reserves space for a separately defined future direction.
When development actually begins, each specialist will record its exact parent
checkpoint and tokenizer hashes and own training configuration, data,
checkpoints and evaluations. No such infrastructure or trained specialist is
created by these placeholders.

The active laboratory stays in `C:\DaveLM-Training\rnc\`; this experiments
workspace remains separate. Model weights are not duplicated here. Its
lightweight family-tree documentation is also published in the existing DaveLM
GitHub repository under `docs/experiments/`. That published directory is a
documentation snapshot, not a relocation of this workspace. This workspace
was not a Git repository when the family tree was established on 2026-10-16.
